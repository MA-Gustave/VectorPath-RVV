# Contributing to VectorPath-RVV (independent fork)

**This is not the upstream simdjson contribution policy.** For historic upstream rules, see `UPSTREAM-CONTRIBUTING.md`. The original upstream source retains its existing licences and credits.

- Discuss planned patches with the independent maintainer before PR submission. A PR does not convey exclusive title by itself. Obtain express documented permission/terms from each contributor before merge; preserve author credits and third-party notices.
- Mark files and changed source ranges with applicable SPDX identifiers or a clearly scoped per-patch notice. Record immutable commits, original expression, coauthors, AI usage, source provenance and first-publication evidence.
- Do not classify an entire mixed-origin upstream file as proprietary. Do not rewrite, delete or obscure original Apache/MIT or third-party copyright notices.
- **Do not submit verified rights-reserved additions to `simdjson/simdjson` for upstream integration without a signed written authorization from the actual rights holder.** This instruction applies to this project's contributors. It does not cancel rights already granted under Apache/MIT or law.
- AI-assisted contributions require meaningful human review, lawful source use, test evidence and ability to explain authorship/technical decisions. Preserve the upstream AI policy as historical context, not as this independent project's submission rules.
- Publication gate: update `PROVENANCE-ADDITIONS.md`, `LICENSE-SCOPE.md`, third-party inventory and copyright notices before distributing new code. If ownership or earlier grants cannot be demonstrated, mark `UNVERIFIED` and do not assert a new exclusive licence.

No submission to this repository is a submission to official simdjson. Independent code improvements remain subject to valid legal rights and licences regardless of this policy.
